# Security and privacy

TalkCut initially operates on trusted local projects. It does not sandbox
untrusted project files, FFmpeg codecs, or external analysis providers.

Originals, rendered lectures, transcripts, review clips and credentials belong in
ignored local project directories. Cloud processing is disabled until explicitly
configured and authorized. The MIT license covers TalkCut code; it does not grant
rights to recordings, dependencies, models or third-party services.

Do not include private paths, media, provider responses or tokens in a public
issue. Report a vulnerability privately through the repository's GitHub security
reporting facility if available; otherwise contact the maintainer without sending
sensitive material publicly. Include a minimal generated reproducer and tool
versions when possible.

Successful FFmpeg decoding is not proof of editorial accuracy. Source identity,
timeline, technical validation, separate audiovisual review and owner acceptance
are distinct evidence and authority boundaries.
